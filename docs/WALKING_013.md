# 0.1.3 步行与地图

无可用地铁方案时继续查询高德步行路线；也可以在地点确认页直接选择步行。步行查询失败会保留目的地和重试、高德入口，不把失败解释为地点不存在。

去地铁站优先使用接口返回的入口坐标；没有入口坐标时使用站点坐标，仍需看现场入口标识。出站后重新定位并规划到最终目的地。站内换乘继续按站内标识，不用室外步行规划替代。

应用内包含高德静态路线地图、预计步行时间、大字逐步指引和刷新按钮。指引手动翻页，地图不持续跟随位置，不自动判断到达。过长的地图请求不抽稀连线，改为提示使用高德查看；地图失败仍保留文字指引。走动后可刷新当前位置和路线。演示路线不请求真实地图或外部导航。

实时步行导航通过官方 OnFootNavi URI 打开已安装高德；系统找不到高德时打开官方 HTTPS 步行路线页。返回助手后保留地铁行程，不自动确认上车或到达。

打车按钮明确标为“打开高德，选择打车”：优先通过官方路线 URI 打开高德客户端，缺失时打开网页。没有获得已验证的直接打车页接口，因此不宣称直接进入打车页，不提交订单、不付款。当前起点由高德重新定位，避免使用过期出发点。

新增模拟器检查覆盖无地铁转步行、进出站步行及返回行程、导航参数编码与无客户端的备用链接。37项领域测试、18项设备回归（17通过，拨号器缺失1跳过）及公共地标真实接口测试通过。真实接口测试包含步行路线和静态地图解码。Lint无错误，17条依赖更新/风格建议。

模拟器未安装高德，未验证高德实际导航界面、打车选择和实际移动定位；这些需要安装高德的手机验收。未修改模拟器定位设置。
