# 0.1.2 信息优先级调整

依据2026-09-21反馈实施：

1. **搜索状态明确**：家庭交付包已配置用户提供的高德 Key，首页可同意并开启定位。未配置的源码默认构建仍为 Demo，首页列出示例词，未知词解释限制。网络或定位失败后可重试真实搜索。不将演示结果当成真实地址。
2. **下车站优先**：路线卡片及当前乘车页以34sp粗体显示“在XXX站下车”，提醒弹窗用36sp红色粗体；通知标题也包含下车站名。线路、乘坐站数、方向及换乘为次级信息，明确此站是换乘还是出站。
3. **时间易读**：分别展示全程、地铁、走路的预计分钟数。Demo医院显示48/24/14分钟，说明总时间含候车。真实步行时间只采用完整有效的接口字段；不按剩余时间或距离暗自推算。
4. **删去密集米数**：老人界面移除“进站前250米·换乘120米·出站后430米”等数据，用“先到XX站”“跟随X号线换乘标识”“出站后步行到目的地”表达当前任务。数据仍用于后台算法。
5. **页面切换归顶**：不同页面使用同一个滚动区时切换回到顶部，防止从首页下方点击后直接看到路线中段。

安全行为保持：提醒可以关闭、不抢其他应用前台、无电话拦截权限、默认无声提醒、可从通知结束行程。

真实搜索使用高德 Web 服务 API，MCP不是运行依赖。公共地标接口测试与老人手机实际定位、实际乘车验收分别记录，不将模拟器结果等同于真机出行验证。
