## 本次依据

设计文件：https://www.figma.com/design/rOZODJxizCFvbtY6SBMOjS

已通过浏览器查看用户修改后的首页、语音输入、候选地点和路线推荐画板。首页采用可滚动的大字常用地点卡片，底部固定“说出目的地 / 输入目的地”；语音页保持顶部返回、中间浅绿回答区、底部操作。Android 中统一24dp内容边距、左对齐和可换行文字，主要操作最小72dp。Figma MCP仍返回Starter额度限制，本次没有回写Figma。

## 对话

手机 SpeechRecognizer 识别中文 → DeepSeek 官方 HTTPS Chat API → 中间显示回复 → 系统 TextToSpeech 朗读。

- 使用官方文档当前列出的 deepseek-flash，非流式短回复，关闭思考输出。
- 支持连续多轮对话、部分识别文字、停止朗读再说、再次朗读、文字回复和直接输入目的地。
- 只保留内存中的最近12条消息，不持久化录音或对话。
- AI返回待搜索地点文字后，用户点击“查看找到的地点”，交给高德/明确标识的演示提供器查询，再手动选择并确认。
- AI不能提供可执行的坐标、车站、路线或行程推进命令。
- 离开前台即停止录音、停止朗读并取消等待；过期识别回调和请求结果不会更新新对话。
- 缺少语音识别/中文TTS时保留文字路径；HTTP 401/403、402、429、超时分别显示可理解的错误。

官方接口参考：https://api-docs.deepseek.com/

## API Key

设置 → 设置/替换 DeepSeek API Key。窗口默认隐藏明文，禁止系统截屏，不把Key放入rememberSaveable。支持替换与清除。

手机保存使用AndroidKeyStore管理AES密钥，AES-GCM加密API Key；备份已在Manifest中关闭。源码、BuildConfig和APK不包含预置DeepSeek Key。

用户提供的Key已经向官方接口做最小连通测试，HTTP 402（余额不足）；没有获得真实AI回答。该Key另在工作区外层工具目录以Windows用户DPAPI加密保存，未写入项目文件。当前没有安装新应用，因此尚未把Key写入任何手机的新设置；首次运行需要通过设置窗口保存Key。

## 原交互问题同步修正

- 顶部返回固定在滚动区外，返回不结束当前行程。
- 候选地点先选择，再独立确认名称、地址与地图。
- 删除步行文字“上一步/下一步”手动翻页，导航明确交给外部高德应用。
- 关闭到站提示只关闭弹窗；只有“我已下车”才推进下一段。
- 单独关闭本段提醒，不改变乘车阶段；误点上车可回候车。
- 结束行程需要确认；换乘后必须重新确认上车。
- 定位/网络失败保留目的地且不自动切演示；没有地铁单独展示替代方式。
